Run on one Android and one iOS device per release candidate; record results in the release PR.

- [ ] Week table at 30 min (default), 1 min, 5 min, 2 h, 24 h (week list); swipe weeks; jump to date.
- [ ] Create by tap and long-press drag; move/resize with snapping; undo.
- [ ] Recurring task: every Mon & Tue; edit "this / this & following / all"; skip; complete.

- [ ] Nested items 10+ levels; indent/outdent; drag reparent; focus mode; attachments offline.
- [ ] Preview mode: complete / waiting (note) / blocked (note) / ongoing; roll-ups.
## Habits & Quit

- [ ] Quit smoking: live counter, relapse, craving, money saved, milestones.
## Notifications

- [ ] Quiet hours, pause-all; inbox shows fired reminders.
## Sync (when cloud configured)
- [ ] Two devices, offline edits on both, reconnect → identical data.
