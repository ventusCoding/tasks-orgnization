# Accessibility walkthrough (T9.1.10)

For each tab (Today, Plan, Lists, Habits, Insights) and each editor:
1. TalkBack / VoiceOver: every control has a label; focus order is logical; custom actions exist on tiles
   (mark done, move 15 min, open).
2. Text scale 200 %: no clipped text; lists scroll.
3. Contrast ≥ 4.5:1 (automated in widget tests with `textContrastGuideline`).
4. Reduce motion: no large animations.
5. Charts: each has a "Show as table" alternative.
